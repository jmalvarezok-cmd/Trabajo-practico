# Vértice - Proyecto Final Front-End (UTN)

Aplicación web desarrollada con React y Vite, migrada desde un sitio estático HTML/CSS como parte del Trabajo Práctico Final del curso inicial de Front-End de la UTN FRBA.

## 🚀 Tecnologías Utilizadas
- **React.js** (con Vite)
- **React Router DOM** (v6) para la navegación entre páginas
- **CSS** modularizado y adaptado de la maquetación original

## ⚙️ Cómo ejecutar el proyecto localmente

1. Clonar o descargar el repositorio en tu computadora.
2. Abrir una terminal en la carpeta raíz del proyecto e instalar las dependencias:
